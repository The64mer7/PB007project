Use Case - Search for available cars link

Name Value
Description

Description:

        The user searches for a suitable car or ride from point A to point B, with the option to select additional accessories for premium users.

Primary actors: User

Secondary actors: -

Preconditions: -

Main flow:

        User clicks the button to search for a ride

        User inputs pickup point, destination, pickup time, number of passengers

        if User is Premium User{

                User gets the option to input wanted equipment}

        System validates all fields

        System searches available rides that fit the User's requirements

        System creates a route from pickup to destination

        System displays available rides to the User

Post-conditions:

        Available suitable rides are displayed to the user

Alternative flow:

        No cars are available:

                User gets the option to change their requirements

       User logs out:

                Action gets canceled

        No route from pickup point to destination has been found by the system:

                User gets the option to change their requirements
