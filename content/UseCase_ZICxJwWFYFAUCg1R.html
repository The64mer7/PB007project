Description:

        The Registered User orders a car by selecting an available ride from the search results and completing the payment process.

Primary actors: Registered User

Secondary actors: Payment provider

Preconditions: The user searched for a ride and at least one ride was provided

Main flow:

        Registered User chooses a ride from the list of available rides

        Registered User is asked to confirm the selected ride

        if Registered User cancels the selection{

                Order ride()}

        else{

                Registered User is asked to fill in card information

                Payment provider Processes payment

                if payment successful{

                        Car sets availability to unavailable

                        System calculates route

                        System sends route to car}}

Post-conditions:

        Car is unavailable, Firm received money

Alternative flow:

        Payment fails:

                User receives an option to retry payment or cancel ride

       User logs out before payment:

                Action gets canceled
